# Post Log

Track every post: what was posted, where, when, and what happened.

## File naming
One file per post: `YYYY-MM-DD_platform_subreddit-or-handle.md`

Example: `2026-04-05_reddit_r-localllama.md`

## Status values
- `draft` — not posted yet
- `live` — posted, watching
- `done` — results collected

## Metrics to track (Reddit)
- Upvotes / upvote ratio
- Comments (count + notable reactions)
- Crossposted anywhere?
- Visible spike in typer.space Umami traffic? (check 24-48h after posting)
- App Store clicks (if trackable)
- Any DMs or follows from it
