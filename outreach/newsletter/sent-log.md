# Newsletter sent log

Authoritative record of who has received which newsletter email. The skill diffs Netlify newsletter form submissions against this log to find new subscribers.

## Format

One section per email campaign. Within a section, one row per recipient: date sent, email, name used (or `—`), one-line note (optional, who the person is if known).
